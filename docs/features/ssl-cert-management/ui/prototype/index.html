/certs/settings · settings.html

只读查看者路由

只读查看者仅可访问到期看板（默认页与唯一菜单入口）与证书详情（只读模式，经看板抽屉「查看证书详情」进入）。以下路由被前端 + EIAM 同步拦截并提示「无权限访问，仅到期看板可见」：

  • /certs（台账） · certs.html
  • /certs/changes、/certs/changes/new、/certs/changes/:id · changes.html / changes-new.html / change-report.html
  • /certs/settings · settings.html

切换上方角色为「只读查看者」后，进入上述拦截页将看到无权限横幅；到期看板可正常访问。
