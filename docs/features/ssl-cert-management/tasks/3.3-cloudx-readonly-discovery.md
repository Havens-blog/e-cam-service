# 3.3: 华为云/AWS/Azure 只读发现（discovery-only CloudDeployer，仅 ListReferences/GetCert，ERR_DISCOVERY_ONLY）

## Description
为华为云/AWS/Azure 三云新增 discovery-only 证书发现适配：仅实现 ListReferences（CDN/DCDN/WAF/LB 证书引用只读扫描）与 GetCert；UploadCert/BindResource/CleanupOrphan 返回哨兵错误 ERR_DISCOVERY_ONLY。三云引用可进台账与覆盖率分母，但进入变更清单时为不可执行项（5.2 处理）。

## Reference Files
- docs/features/ssl-cert-management/design/tech-design.md — Interfaces / Interface 2: CloudDeployer（per 云 per 产品）、Error Handling / Error Types & Codes
- docs/features/ssl-cert-management/prd/prd-spec.md: Out of Scope（三云部署器二期）与 In Scope 引用发现全云 (ref: Interface 2: CloudDeployer（per 云 per 产品）)
- docs/features/ssl-cert-management/design/schema.sql: cert_references cloud 枚举 huawei/aws/azure (ref: Error Handling / Error Types & Codes)

## Acceptance Criteria
- [ ] huawei/aws/azure 三云各新增 discovery 适配：ListReferences(product) 返回 CloudCertRef 列表（含 referencedCloudCertId），GetCert 返回 CloudCertInfo。
- [ ] UploadCert/BindResource/CleanupOrphan 统一返回 sentinel `ErrDiscoveryOnly`（错误码语义 ERR_DISCOVERY_ONLY），不得产生任何云侧写操作。
- [ ] 三云凭证复用既有 cloudx 账号体系（huawei/aws 已有目录；azure 目录缺失则新建 `internal/shared/cloudx/azure/` 最小适配）。
- [ ] 产品覆盖：三云的 CDN/WAF/LB 证书引用面（各云以实际产品映射，枚举对齐 cert_references.product）。
- [ ] mock 单元测试：ListReferences/GetCert 成功路径 + 三写方法返回 ErrDiscoveryOnly 断言。
- [ ] `go build ./internal/shared/cloudx/...` 全绿，additive。

## Hard Rules
- 只读硬约束：三云适配文件中不得出现任何云侧写 API 调用（代码评审口径）。
- Additive only：不修改既有 huawei/aws 适配签名。

## User Stories
Story 2（查看证书引用关系 — 三云引用可见）；换证不可执行项提示见 Story 3 AC（首期无部署器分区）。

## Implementation Notes
- 新增：`internal/shared/cloudx/huawei/cert_discovery.go`、`internal/shared/cloudx/aws/cert_discovery.go`、`internal/shared/cloudx/azure/cert_discovery.go`（azure 目录为新建）+ 各 `*_test.go`。
- `ErrDiscoveryOnly` 定义在 cloudx 公共 errors（与 3.1/3.2 的 ErrCloudRateLimited 同处）。
- Azure 无既有 client 基座：仅做证书发现所需最小凭证加载（复用平台云账号存储的 azure 凭证字段），不做全量资源适配。
