# 6.3: 详情与引用关系组件（UF-2：要素卡/正反向 Tab/盲区横幅/扫描防重/筛选）

## Description
构建 /certs/:id 证书详情与引用关系页：要素卡（SAN chips/issuer/指纹复制/有效期进度条/私钥"已加密托管"/关联变更历史）、引用关系卡（正反向 Tab、盲区声明横幅常驻、扫描元数据+立即扫描[防重]、正向分组折叠+级联筛选+资源名搜索、反向查询、资源抽屉）。

> 跨仓库任务：文件位于 e-cam-web 仓库，路径为仓库相对路径。

## Acceptance Criteria
- [ ] 要素卡：左 SAN chips（折叠+N）/issuer/指纹(mono 可复制)/托管状态徽章；右 有效期进度条(剩余天数状态色)/私钥"已加密托管"/关联变更历史列表（按 certId 过滤倒序）。
- [ ] 引用卡：正向|反向 Tab；正向盲区横幅"本视图不含 VM Nginx 配置级引用"常驻不可关闭；扫描元数据行（最近扫描时间+各云覆盖率，total=-1 显示"分母不可用"）+ 立即扫描按钮（超期时显示）。
- [ ] 立即扫描防重：进行中按钮 disabled+"扫描中"+轮询任务，完成后刷新元数据；重入/刷新直接恢复"扫描中"态轮询；服务端 409 SCAN_IN_PROGRESS 不新建任务、返回进行中态。
- [ ] 正向分组折叠（cloud·product），筛选 云▾/产品▾/集群▾级联（集群仅 K8s 组显示）+ 资源名搜索 300ms 防抖（清空恢复全量）；无匹配分组显示"无匹配引用"空态；资源行点击 → 右抽屉展示资源要素。
- [ ] 反向查询：域名/资源名搜索 → 证书卡片列表（按指纹分组并存区分）；无匹配 → "未查询到引用该域名/资源的证书"（区别于未查询的初始态）。
- [ ] 未发现引用态显示"未发现引用（≠ 无引用）· 最近扫描 X 前"（区别于空态）；只读模式隐藏"立即扫描"等操作入口；a11y 焦点陷阱/aria-live 合规。

## Hard Rules
- 盲区声明横幅不可关闭、不可被筛选隐藏。
- 同域名多证书并存按指纹严格区分，不合并展示。
