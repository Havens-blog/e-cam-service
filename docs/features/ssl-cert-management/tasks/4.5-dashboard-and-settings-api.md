# 4.5: 到期看板与配置 API（dashboard summary/items、settings CRUD、exemptions、crds 端点、thresholds 界值校验、test 告警）

## Description
看板与全局配置端点：GET /dashboard（summary 5+2 卡 + items 子域名行，全角色含只读）、settings CRUD（告警接收+阈值+豁免+CRD 登记）、exemptions 增删、crds 端点（接 3.4 service）、thresholds 越界校验（400）、settings/test 测试告警。Auth 主管/审计对 settings，全角色对 dashboard。

## Reference Files
- docs/features/ssl-cert-management/design/tech-design.md — 登记覆盖率 / 可更换托管覆盖率（双指标口径）、自定义 CRD 登记管理、探测目标域来源与通配符处置（wildcardSkippedCount）
- docs/features/ssl-cert-management/design/api-handbook.md: dashboard / settings / exemptions / crds 端点契约 (ref: 登记覆盖率 / 可更换托管覆盖率（双指标口径）)
- docs/features/ssl-cert-management/design/schema.sql: cert_alert_config thresholds 界值与 wildcardProbeOverrides (ref: 自定义 CRD 登记管理)

## Acceptance Criteria
- [ ] `GET /api/v1/certs/dashboard`：`{summary{countsByLevel[5],diffAlertCount,exemptCount,wildcardSkippedCount,registrationRate,replaceableRate,fingerprintOnlyRate}, items[]{domain,daysLeft,level,hostingType,probeStatus,referencedClouds[]}, lastInspectionAt}`；三个 rate 口径同 2.3 stats；全角色可访问。
- [ ] `GET/PUT /api/v1/certs/settings`：webhookUrls/emailGroup/verifyWindowRoute/wildcardProbeOverrides/thresholds 读写；thresholds 越界 → 400（scanFreshnessHours 1~72、verifyWindowHours 2~24、rollbackProtectDays 7~14、verifyConfirmProbes 1~10、verifyProbeIntervalMinutes 5~60、pauseTimeoutHours 24~168、recheckDelayMinutes 1~60、itemHeartbeatTimeoutMinutes 5~180、scanTimeoutHours 1~12、expiryLevels 非空 1~5 项 1~90）。
- [ ] `POST/DELETE /api/v1/certs/settings/exemptions[/:domain]`：豁免增删，审计留痕（7.2）；`POST/GET/DELETE /api/v1/certs/settings/crds[/:id]`：接 3.4 service，重复登记 → 409。
- [ ] `POST /api/v1/certs/settings/test`：经 4.3 通道发测试告警，返回成功/失败原因。
- [ ] 鉴权：settings/crds/exemptions/test 限运维主管/审计（FORBIDDEN 403 否则）；dashboard 全角色（含只读）。
- [ ] httptest：dashboard 口径（countsByLevel/wildcardSkippedCount/rate 字段）、thresholds 各界值边界（含越界 400）、crds 重复 409、权限矩阵。

## Hard Rules
- thresholds 界值必须服务端校验（不得仅前端校验）；越界 PUT 整体拒绝（不做部分写入）。
- dashboard/settings 响应不含任何私钥/凭证；webhookUrls 不回显敏感凭据字段（URL 本身为配置可见，但 SMTP 密码等不返回）。

## User Stories
Story 6（查看到期看板 — dashboard 数据源）、Story 5（审计与告警配置 — 全局配置页后端）。

## Implementation Notes
