# 3.1: cloudx 阿里云证书 API（UploadCert/ListReferences/BindResource/GetCert/CleanupOrphan，CDN/DCDN/WAF/ALB(NLB)）

## Description
扩展 `internal/shared/cloudx/aliyun`：实现证书域五方法（UploadCert 两段式第一段/BindResource 第二段/ListReferences 只读发现/GetCert 回滚目标校验/CleanupOrphan 孤儿清理），覆盖 CDN/DCDN/WAF/ALB(NLB) 产品。纯云 SDK 适配层，additive，不破坏 cloudx 既有接口。

## Reference Files
- docs/features/ssl-cert-management/design/tech-design.md — Interfaces / Interface 2: CloudDeployer（per 云 per 产品）、Dependencies
- docs/features/ssl-cert-management/design/schema.sql: cert_references cloud/product 枚举（aliyun: cdn/dcdn/waf/alb/nlb） (ref: Interface 2: CloudDeployer（per 云 per 产品）)
- docs/features/ssl-cert-management/design/tech-design.md: 限流退避与 K8S_UNREACHABLE 映射 (ref: Error Handling / Error Types & Codes)

## Acceptance Criteria
- [ ] `internal/shared/cloudx/aliyun` 新增证书 API 适配：UploadCert(ctx, creds, product, name, pem, key)→cloudCertId；BindResource(ctx, creds, product, resourceId, cloudCertId)；ListReferences(ctx, creds, product)→[]CloudCertRef；GetCert(ctx, creds, cloudCertId)→CloudCertInfo{Exists,NotAfter,Fingerprint}；CleanupOrphan(ctx, creds, cloudCertId)。
- [ ] 产品覆盖：cdn/dcdn/waf/alb/nlb 五类，按产品映射到对应阿里云 OpenAPI（CDN/DCDN/WAF/ALB 或 SLB/NLB 证书与绑定接口）。
- [ ] 凭证复用既有 aliyun client/账号体系（client.go/converter.go 同风格），不新建凭证存储。
- [ ] 云 API 限流/流控错误 → sentinel `ErrCloudRateLimited`（CLOUD_API_RATELIMITED 语义）；未实现产品/接口缺失 → 显式错误而非静默。
- [ ] mock SDK 单元测试：五方法成功路径 + 限流路径 + ListReferences 分页遍历；不依赖真实云账号。
- [ ] `go build ./internal/shared/cloudx/...` 与既有 cloudx 测试全绿（additive：不修改既有接口签名与既有文件行为）。

## Hard Rules
- Additive only：不修改 `internal/shared/cloudx` 既有接口/方法签名；新代码放新文件（cert_*.go）。
- 不在适配层做业务编排（两段式编排属 5.3/5.4）；本层仅单次 API 调用封装。

## User Stories
Story 2（查看证书引用关系 — 阿里云引用发现）、Story 3（一键批量更换 — 阿里云两段式执行）。

## Implementation Notes
- 新增文件：`internal/shared/cloudx/aliyun/cert.go`（入口+公共类型）、按产品拆 `cert_cdn.go`、`cert_dcdn.go`、`cert_waf.go`、`cert_lb.go`（ALB/NLB 合并）+ 对应 `*_test.go`。
- 阿里云证书相关 API 以官方 OpenAPI（cas/cdn/dcdn/waf/slb/alb 域）为准；SDK 版本沿用仓库现有 aliyun SDK 依赖，必要时用 OpenAPI 元数据直调（与 5.12 PoC 结论联动，PoC 未出前先按公开文档实现+mock 测试）。
- CloudCertRef 结构对齐 CertReference 落库字段需求：cloud/product/resourceId/referencedCloudCertId/accountKey。
