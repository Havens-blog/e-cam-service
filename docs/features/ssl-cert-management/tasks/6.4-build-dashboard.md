# 6.4: 到期看板组件（UF-3：5+2 卡联动筛选/探测四态/抽屉）

## Description
构建 /certs/dashboard 到期看板页：5 级总览卡（>30/≤30/≤14/≤7/已过期）+ 2 次级卡（差异告警数/探测豁免数，可点联动筛选）；表格（子域名+云 chips/剩余天数状态色徽章/托管类型/线上探测四态/豁免）；行抽屉（证书要素+最近探测+复制差异摘要+查看证书详情）；筛选（状态分级/云多选/托管类型）；全角色兼容（只读无操作入口）。

> 跨仓库任务：文件位于 e-cam-web 仓库，路径为仓库相对路径。

## Acceptance Criteria
- [ ] 5 总览卡 + 差异告警卡 + 豁免卡（同等卡片形态）：点击卡 → 表格按该维度过滤，选中卡 Accent 高亮，再点取消；summary 含 countsByLevel[5]/diffAlertCount/exemptCount/wildcardSkippedCount + 三 rate 字段。
- [ ] 表格列：子域名(下行附 referencedClouds chips)/剩余天数(状态色徽章)/托管类型/线上探测(probeStatus 四态)/豁免；筛选 状态分级▾/云▾(多选按 referencedClouds 过滤命中其一)/托管类型▾；最近巡检时间。
- [ ] probeStatus 渲染：一致=Success✓；差异=Error 角标+「差异」+最近探测时间 tooltip；不可达=Text Secondary+⚠+「不可达」（不参与差异告警）；豁免=Secondary+✓+「豁免」；非色觉通道（图标+文字）。
- [ ] 行点击 → 右抽屉：证书要素+最近探测详情(时间/线上指纹/差异说明)+ 复制差异摘要 + 查看证书详情链接（跳转 /certs/:id，全角色可达）。
- [ ] 只读查看者：本页无变更类操作入口；仅保留"复制差异摘要"与"查看证书详情"；差异告警由巡检自动触达（不要求只读者人工上报）。
- [ ] 四态齐备：loading/empty（"暂无证书，等待导入"）/error/populated；差异行角标；a11y 状态卡 aria-live polite 通告筛选变化。

## Hard Rules
- 不可达不得计入差异告警渲染（区别于豁免：豁免是人工排除，不可达是探测失败需关注）。
- 只读角色页面不得出现任何操作入口（扫描/发起更换/配置等）。

## User Stories
Story 6（查看到期看板 — 全部 AC）、Story 5（探测豁免不参与常规差异）。
