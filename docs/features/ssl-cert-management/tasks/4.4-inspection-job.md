# 4.4: 定时巡检任务（完整性复检+到期分级+TLS 探测调度+豁免过滤，天级）

## Description
组装天级巡检流水线 Job：完整性复检（复跑 2.1 解析校验存储证书仍可解析且未过期）、到期分级（4.2）、TLS 探测调度（4.1）、豁免过滤（豁免域名仍探测但 exempt 不告警）。提供可被 7.1 调度的 Job 入口；探测/分级内部已就绪，本任务做编排与幂等。

- docs/features/ssl-cert-management/design/tech-design.md: 到期分级去重与 TLS 探测目标域 (ref: 到期分级告警（去重状态机）)

## Acceptance Criteria
- [ ] Job 入口 `RunInspection(ctx)`：顺序/受控并发执行四步——完整性复检、到期分级计算与去重告警、TLS 探测调度（台帐全部 sans）、豁免过滤（豁免域名探测记 exempt 不告警）。
- [ ] 完整性复检：复跑 2.1 校验存储证书可解析/未过期/链完整；异常项产生异常事件（计入巡检健康，不计入业务四类告警或归入运维处置类）。
- [ ] 记录 lastInspectionAt（供 dashboard 展示）与各子步成功率指标（供平台自身监控）。
- [ ] 幂等：重复执行同一日不产生重复到期告警（依赖 4.2 去重）；单证书/单域名失败不中断整轮巡检。
- [ ] 集成测试：完整一轮巡检（mock 台帐+探测）断言到期告警只发一次、probe 全量域名、lastInspectionAt 更新。

## Hard Rules
- Job 内不得做云侧写操作；仅只读探测与告警发布。
- 天级粒度：不提供分钟级巡检（探测提频仅在验证窗口，由 5.10 控制）。

## User Stories
Story 5（审计与告警配置 — 巡检驱动告警触达）、Story 6（到期看板 — 巡检数据来源）。
