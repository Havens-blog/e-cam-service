# 2.3: 台账查询/删除拦截/统计（列表筛选分页、保护期删除拦截 CERT_HAS_REFS、GET /stats 双口径覆盖率）

## Description
台账读取面：证书列表（分页+hostingStatus/daysLeft 筛选+search）、详情（不含私钥）、删除拦截（引用三态 + 保护期）、以及 GET /stats 覆盖率双指标（登记覆盖率/可更换托管覆盖率/仅指纹占比，分母=最新成功快照指纹去重 ∪ 台账全部指纹，实时聚合无存储快照）。

## Reference Files
- docs/features/ssl-cert-management/design/tech-design.md — 引用状态语义（"未发现引用" ≠ "无引用"）、登记覆盖率 / 可更换托管覆盖率（双指标口径）
- docs/features/ssl-cert-management/design/api-handbook.md: 列表/详情/删除端点与 /stats 响应字段 (ref: 引用状态语义（"未发现引用" ≠ "无引用"）)
- docs/features/ssl-cert-management/design/schema.sql: cert_certificates 字段与索引 (ref: 登记覆盖率 / 可更换托管覆盖率（双指标口径）)

## Acceptance Criteria
- [ ] `GET /api/v1/certs`：服务端分页（每页 20）+ hostingStatus/daysLeft 筛选 + search（域名/SAN/指纹片段）；响应含 commonName/sans/issuer/notAfter/daysLeft/hostingStatus/protectUntil/refCount，不含任何私钥字段。
- [ ] `GET /api/v1/certs/:id`：全要素详情；encryptedPrivateKey 永不出现，前端仅见"已加密托管"语义（后端返回 hasKey bool 或等价）。
- [ ] 删除拦截：引用三态派生 referenceStatus——has_refs 与 blind_spot → 409 CERT_HAS_REFS（blind_spot 附盲区原因）；仅 no_refs_scanned 且不在保护期（protectUntil < now）允许删除；保护期内 → 409 CERT_HAS_REFS（附保护期截止时间）。
- [ ] `GET /api/v1/certs/stats` 响应：`{total, complete, fingerprintOnly, missingRegistrations, registrationRate, replaceableRate, fingerprintOnlyRate, denominator, denominatorSources{scannedUniqueFingerprints, manualOnlyFingerprints}}`，查询时实时聚合。
- [ ] 分母口径正确：最新成功（status=done）ScanSnapshot 的 CertReference 指纹去重 ∪ 台账全部指纹；missingRegistrations=扫描发现未登记数；fingerprintOnlyRate=台账内占比。
- [ ] httptest：列表筛选/分页、删除三分支（has_refs/blind_spot/no_refs_scanned+保护期）、stats 口径（构造扫描指纹与台账指纹部分重叠的夹具验证并集去重）。

## Hard Rules
- 覆盖率不落存储快照，每次查询实时聚合；分母不得退化为"台账数"（防自指）。
- 详情/列表响应字段白名单序列化：encryptedPrivateKey 密文与明文均不得出现在任何 JSON。

## User Stories
Story 1（台账与详情）、Story 4（存量导入统计：登记覆盖率与可更换托管覆盖率两指标 + 仅指纹占比单独可见）。

## Implementation Notes
- 新增：
  - `internal/cert/service/ledger_service.go`（列表/详情/删除/统计 + referenceStatus 派生 helper）
  - `internal/cert/web/ledger_handler.go`（GET /api/v1/certs、GET /:id、DELETE /:id、GET /stats）
  - `internal/cert/service/ledger_service_test.go`、`internal/cert/web/ledger_handler_test.go`
- referenceStatus 派生规则（tech-design"引用状态语义"节）：最新成功快照中该指纹计数>0 → has_refs；快照已覆盖该证书涉及云/产品且计数=0 → no_refs_scanned；无成功快照或未覆盖 → blind_spot。
- daysLeft 筛选分档与前端筛选器对齐（>30 / ≤30 / ≤14 / ≤7 / 已过期）。
