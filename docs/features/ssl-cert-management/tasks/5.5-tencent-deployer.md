# 5.5: 腾讯云部署器（同 5.4）

## Description
腾讯云 CloudDeployer 实现：与 5.4 对称，将 3.2 cloudx 腾讯云证书 API 组装为部署器，覆盖 CDN/EdgeOne(WAF)/CLB 产品；经 5.3 CloudAPIChannel 编排；限流退避有上限；产出 DeployResult。

## Acceptance Criteria
- [ ] TencentDeployer 实现 CloudDeployer 覆盖 cdn/waf(EdgeOne)/clb 三产品；按 DeployTarget.product 路由到 3.2 适配方法。
- [ ] Deploy 返回 DeployResult{NewCloudCertID, OldCloudCertID, OrphanCandidate}；OldCloudCertID 从引用快照读取。
- [ ] 限流 `ErrCloudRateLimited` → 有界退避重试，耗尽 → failed；第二段失败 → CleanupOrphan 补偿 + OrphanCandidate=true。
- [ ] mock SDK 测试：两段式成功/第二段失败补偿/限流耗尽/三产品路由。
- [ ] `go build ./internal/cert/...` 全绿；与 5.4 结构一致便于 CloudAPIChannel 统一消费。

## Hard Rules
- 退避重试必须有上限，禁止无限重试。
