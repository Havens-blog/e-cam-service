# 5.2: 清单生成（指纹聚合、4 项前置校验含 NEW_CERT_FINGERPRINT_ONLY、SAN 预检、不可执行项分区、盲区声明、快照绑定）

## Description
GenerateChangeList：按 oldFingerprint 聚合最新成功快照的 CertReference 生成 ChangeListItem（持久化完整 DeployTarget 于 resourceRef，按 action 分支必填字段），绑定 snapshotId，做四项前置校验阻断（SCAN_STALE/SAN_INSUFFICIENT/CHANGE_IN_FLIGHT/NEW_CERT_FINGERPRINT_ONLY），SAN 预检（新证书 SAN ⊇ 目标域名），不可执行项/不可自动变更分区 + 盲区声明写入 Warnings。

## Acceptance Criteria
- [ ] `GenerateChangeList(ctx, oldFingerprint, newCertId) (ChangeList, error)`：聚合最新成功（status=done）ScanSnapshot 中该指纹的 CertReference，逐项生成 ChangeListItem（resourceRef 按 action 分支：cloud_api={channel,cloud,product,accountKey,resourceId}；patch_crd={channel,clusterId,namespace,kind,resourceId}）。
- [ ] 四项前置校验阻断 → 409：扫描超期（now-startedAt > scanFreshnessHours）→ SCAN_STALE；新证书 SAN ⊉ 目标域名（Missing 非空）→ SAN_INSUFFICIENT；同 oldFingerprint 已有活跃单（activeMutex）→ CHANGE_IN_FLIGHT；新证书 hostingStatus≠complete（fingerprint_only 无私钥无法上传云证书库）→ NEW_CERT_FINGERPRINT_ONLY。
- [ ] 不可执行项分区：discovery-only 云（huawei/aws/azure）引用 → AutoChangeable=false + Reason（首期无部署器）；K8s 三信号判定（实际探测在 5.6，本任务对标记来源预留接口/或由 5.6 在扫描期标记）→ AutoChangeable=false + Reason；不可执行项不计入执行成功率分母。
- [ ] 盲区声明写入 Warnings：覆盖边界"不含 VM Nginx 配置级引用"、blind_spot 项提示、coverageMeta total=-1 时"分母不可用"提示。
- [ ] ChangeList 持久化预生成订单（pending_confirm）+ 绑定 snapshotId + ScanFreshnessHrs；SAN 预检结果（Passed/Missing/NewSANs）。
- [ ] 单元测试：四阻断场景各一次命中、SAN 预检 Missing/通过、不可执行项分区与 Warnings、resourceRef 分支必填字段。

## Hard Rules
- 四阻断必须前置在清单生成期（不得延后到 Execute），任何一项不满足不生成可执行清单。
- 不可执行项分区不得静默放行（必须在 Warnings/分区显式声明原因与出路）。

## User Stories
Story 3（一键批量更换 — 清单生成+SAN 预检+不可执行项+盲区声明 AC 对应）。
