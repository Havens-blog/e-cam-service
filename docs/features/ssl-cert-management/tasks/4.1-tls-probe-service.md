# 4.1: TLS 主动探测（SNI 拨测、通配符 wildcard_skipped+override、豁免、change_linked_diff 关联）

## Description
ProbeService：对台账全部 Certificate.sans 展开去重域名做 TLS 握手探测（SNI），抓取线上生效证书计算指纹/有效期，与台账比对得出六态 status（consistent/diff/change_linked_diff/unreachable/exempt/wildcard_skipped）；通配符 SAN 默认跳过（可经 wildcardProbeOverrides 指定具体子域名替代探测）；豁免域名仍探测但标 exempt 不告警；验证窗口内 diff 且命中 verifyExpected → change_linked_diff 并关联 orderId。

## Acceptance Criteria
- [ ] 探测目标域=台账全部 sans 展开去重（expectedDomain 不参与）；逐域名 `tls.Dial` 带 SNI，读 peer 证书 → onlineFingerprint（SHA256）+ onlineNotAfter，写 ProbeResult{domain, probeAt, status}。
- [ ] 状态判定：线上指纹与台账该域名归属证书一致 → consistent；不一致 → diff；拨号失败/DNS 失败/超时 → unreachable（不参与差异告警）。
- [ ] 通配符 SAN（`*.example.com`）→ 不拨测，写 ProbeResult{domain=通配符 SAN, status=wildcard_skipped}；AlertConfig.wildcardProbeOverrides 配置了 concreteSubdomainOverride → 对该子域名正常拨测，结果记于子域名、按常规状态判定。
- [ ] 豁免清单命中域名 → 仍探测但 status=exempt（不触发常规差异告警）。
- [ ] change_linked_diff：diff 时查活跃验证中订单（verifyWindowUntil > now）的 verifyExpected，domain ∈ domains 且 onlineFingerprint == newCertFingerprint → status=change_linked_diff + changeOrderId。
- [ ] 集成测试：本地起 TLS server（多证书 SNI）覆盖六态 + override + 窗口关联；探测结果按 TTL 索引自然过期不主动清理。

## Hard Rules
- 探测超时受控（单域名 dial timeout 常量化，整体批量并发受控）；单域名失败不中断整轮探测。
- 探测仅做 TLS 握手读证书，不发送应用层请求。

## User Stories
Story 6（查看到期看板 — 探测状态数据源）、Story 5（豁免清单不参与常规差异告警）。

## Implementation Notes
- 新增：`internal/cert/service/probe_service.go` + `probe_service_test.go`。
- 标准库 `crypto/tls`（InsecureSkipVerify 仅用于读取对端证书——按 SNI 指定 ServerName，验证目标域归属而非链信任）。
- 台账域名→证书归属映射：sans 反查（多证书同域名并存时逐证书比对，diff 判定按"与任一归属证书一致=consistent"或按最新台账语义，取 tech-design"探测目标域来源"节并在测试固定行为）。
- 验证窗口提频与达标判定在 5.10；本任务提供单轮探测函数 `ProbeDomains(ctx, domains []string)` 供天级与提频共用。
