# 5.9: 孤儿清理与 CRD 复检消费者（orphan-cleanup 队列消费、映射表状态流转、crd-recheck 任务）

## Description
两个异步消费者：(1) orphan-cleanup——OrphanCandidate=true 且归属变更单验证达标/终态后入清理队列，消费者逐项调 CleanupOrphan，结果写入 ChangeReport.OrphanCleanup，失败项运维处置告警；(2) crd-recheck——patch_crd 项 patch 完成后延迟 recheckDelayMinutes 消费，调 5.6 RecheckCRDField 单轮复检。CloudCertMapping 状态流转 active→orphan→清理。

## Acceptance Criteria
- [ ] orphan-cleanup 消费者：天级批扫 + 事件触发（验证窗口达标关闭后即时消费该单清理队列）逐项调 CleanupOrphan；结果 OrphanCleanupResult{cloud,cloudCertId,action,success,at} 写入变更报告。
- [ ] CloudCertMapping 状态流转：active→orphan（第二段失败或回滚时）→ 清理成功后删除/标 cleaned；清理失败保留 orphan + 运维处置告警（不计入 PRD 四类业务告警）。
- [ ] crd-recheck 消费者：patch_crd 项 patch 完成后延迟 recheckDelayMinutes 入队，消费调 5.6 RecheckCRDField 单轮复检；通过→success，回写→failed+告警；复检次数固定 1，失败转人工。
- [ ] 消费幂等：重复消费同一项不产生重复结果/重复告警（以项 ID + 动作去重）。
- [ ] 集成测试（mock 通道 + 队列）：孤儿清理成功/失败两条路径、映射状态流转、crd 复检通过/回写失败、幂等。

## Hard Rules
- orphan-cleanup 不得清理仍在 active（未替换完成）或保护期内的云证书。
- crd-recheck 失败不自动二次复检（转人工）。
