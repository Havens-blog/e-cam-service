# 5.11: 变更管理 API（列表/详情/confirm/execute/rollback/progress/audit 按单查询、报告 ChangeReport 全字段）

## Description
变更管理 HTTP 端点：列表（状态筛选）、生成清单（POST）、详情/报告（GET，ChangeReport 全字段）、confirm/execute/confirm-batch/cancel、progress 逐项轮询、rollback、audit 按变更单号查询审计流水。全部错误码映射按 api-handbook。

- docs/features/ssl-cert-management/design/api-handbook.md: 变更管理端点全集与错误码契约 (ref: Interface 3: ChangeService（变更单生命周期）)
- docs/features/ssl-cert-management/design/tech-design.md: 同步错误 vs 异步子任务状态 (ref: Service-Level Types（非持久化载荷定义）)

## Acceptance Criteria
- [ ] `GET/POST /api/v1/certs/changes`：列表状态 Tab 筛选；POST 生成清单四阻断映射 409（SCAN_STALE/SAN_INSUFFICIENT/CHANGE_IN_FLIGHT/NEW_CERT_FINGERPRINT_ONLY）；`GET /:id` 详情含 ChangeList 结构。
- [ ] `POST /:id/confirm`（batchConf 越界 400/MaxBatchRatio>0.5 拒绝）、`/:id/execute`、`/:id/confirm-batch`（409 BATCH_NOT_CONFIRMABLE）、`/:id/cancel`（409 CHANGE_NOT_CANCELLABLE）。
- [ ] `GET /:id/progress`：逐项状态轮询响应（itemStates：pending/running/success/failed/rate_limited/rolled_back/skipped + error + 批次）。
- [ ] `POST /:id/rollback`：仅成功项；无效目标 409 ROLLBACK_TARGET_INVALID（附转人工提示语义）。
- [ ] `GET /:id/audit`：`{logs[]{at,actor,action,detail,itemId?}}`，action 覆盖 create/confirm/execute/item_result/rollback/verify/orphan_cleanup，可与 ChangeReport 逐条比对。
- [ ] 报告 `GET /:id`（终态）返回 ChangeReport 全字段：OrderID/Status/Summary{Total,Success,Failed,Skipped,RolledBack}/Items/Verify{WindowUntil,ExpectedNew,ProbePass,ProbeDiff,ProbeSkipped,Unmet}/OrphanCleanup[]/UnmetDomains/FinishedAt；响应无任何私钥/密文/凭证字段。

## Hard Rules
- 异步执行失败不得以 HTTP 错误返回（走 status 字段）；仅同步路径错误映射 4xx/5xx。
- audit 端点返回审计流水不得被修改/补写（只读查询）。

## User Stories
Story 3（一键批量更换 — 全生命周期入口）、Story 5（报告与审计逐条比对一致 AC）。
