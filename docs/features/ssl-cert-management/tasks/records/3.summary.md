### 4. Conventions Established
- 五云适配签名同构（creds+product 参数化）；SDK 一律窄接口+可注入工厂实现 mock 测试，不引入 mock 框架；additive-only（cloudx 侧仅新增 cert_*.go，零修改既有适配器与既有文件）
- 哨兵语义跨层传递：限流/流控映射 ErrCloudRateLimited 不在适配层自动重试（退避重试属 5.x 变更编排层）；幂等口径：CleanupOrphan 对已删除幂等成功、GetCert 不存在返回 Exists=false 而非错误
- 云侧证书无法复核（SHA-1 指纹形态）或无法解析引用 → 占位指纹/盲区声明处理并统一登记 PoC 5.12 验证（代码注释标注），不在适配层吞掉或报错中断
- K8s 明文凭证边界：落库仅 AES-256-GCM 信封密文（keyVersion），读取白名单视图，明文用后 Zeroize；kubeconfig 内容片段永不出现在日志/响应/错误 message
- 扫描分母经 AssetCountSource 端口唯一入口（防自指），启动时一次性固化；discovery-only 通道全程只读，绝不触发云侧写 API
- 新增仓储接口方法须同步补 certtest fake；schema 字段变更三层同步（schema.sql+validators.go+models_test），MongoDB 校验器允许附加属性以兼容演进
- web 层沿用 {success,data,error,meta} 信封与固定安全文案映射；新增哨兵错误码→HTTP 映射统一在 response.go 注册（如 SCAN_IN_PROGRESS→409）
