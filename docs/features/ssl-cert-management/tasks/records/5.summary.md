### 4. Conventions Established
- 互斥正确性归 DB 部分唯一索引（uk_active_mutex，insert 与 update 双路径索引强制）：应用层预检查仅快速失败；终态迁移与 token 清除在同一原子 update，防终态单残留 token 阻塞新单
- 不可执行项不静默：持久化即 status=skipped+Reason、不计执行成功率分母；探测/发现单点失败不阻塞清单生成与其他目标（显式分区+盲区声明）
- deployer 层零业务状态机：回滚三判定、孤儿标记、复检告警、OrphanCleaned 回填归 service 层编排；deployer 仅无状态 API 编排+有界重试+幂等清理
- 凭证明文零生命周期：按值传递副本方法返回前 Zeroize+防御性 String() 仅元数据；错误链/日志/响应/审计无私钥凭证片段（测试渗透式断言）
- 限流双闸：部署器级有界重试（固定序列+次数与总时长双闸，errors.Is 透传哨兵）+引擎级二级退避（MarkRateLimited 保活心跳防超时误判）；退避参数缺省保守+With*RetryPolicy 供 config 注入
- 消费侧端口+nil 安全默认模式（ExecuteAlertNotifier/RollbackAuditRecorder/OrphanCleanupRecorder/VerifyWindowRecorder/VerifyWindowSealer/ManagementProbe/BatchVerifyChecker）：生产接线统一 7.x，nil=no-op 安全降级不阻断主流程
- 幂等载体持久化：recheckedAt 扫描排除+MarkRecheck CAS、清理 recorder (orderID,cloudCertId,action,success) 四元组去重+成功删映射（状态机二值）、项级领取 CAS、整单取消两步可重试收敛
- 新增仓储接口方法须同步 certtest fake；模型↔schema.sql↔validators 1:1 一致性为强制门禁（recheckedAt/rollback_failed 三处同步先例）
- 装配边界：生产装配/调度注册/ioc 顺延 7.1（RegisterDeployer、TaskxItemDispatcher、各 scheduler 入口），审计写入与报告存档接线归 7.2（延续 Phase 2/3/4 先例）
- 告警口径延续 Phase 4：四类业务告警之外运维处置走 AlertCategoryOps；change_linked 仅状态迁移发布、窗口关闭恢复常规通道；回滚失败立即告警转人工
- 上传命名逐次唯一公式 ecam-{指纹前8}-{unix秒}-{随机4hex}（aliyun ≤63/tencent ≤50 防御性截断），命名/冲突重试换名不占退避睡眠；ListReferences 占位指纹公式与 3.5 同源可对账
