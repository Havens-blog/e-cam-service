### Key Decisions
- daysLeft filter tiers use query tokens gt30/le30/le14/le7/expired, translated to notAfter ranges (expired=notAfter<=now; leN=now<notAfter<=now+N*24h; gt30=notAfter>now+30d) at service layer so the repository stays a pure range query
- referenceStatus 'involved clouds/products' derived from the fingerprint's cumulative cross-snapshot reference history; empty involvement set is vacuously covered by any successful snapshot (no_refs_scanned), blind_spot requires no done snapshot or uncovered cloud/product pairs in the latest done snapshot's coverageMeta
- list refCount and stats denominator both sourced from the latest status=done snapshot only; running/failed snapshots never contribute (failed-snapshot exclusion test)
- delete interception returns typed *domain.DeleteBlockedError mapped to 409 CERT_HAS_REFS with structured meta {referenceStatus, refCount, reason, protectUntil} so blind-spot reason and protection deadline are machine-readable
- stats computed fresh on every request from repositories (Hard Rule: no stored snapshot); rates rounded to 4 decimals, ratio guards y=0
- search uses regexp.QuoteMeta + case-insensitive $regex across commonName/sans/fingerprint, mirroring internal/cam/tag conventions
