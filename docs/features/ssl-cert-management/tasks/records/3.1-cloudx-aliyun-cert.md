### Key Decisions
- 两段式第一段统一走 CAS UploadUserCertificate：CDN/DCDN/WAF 返回纯数字 ID，ALB/NLB 返回 {certId}-{region} 形态（监听引用证书的标准 ID 形态），GetCert/CleanupOrphan 自动归一化后缀
- CDN/DCDN 绑定用 SetCdnDomainSSLCertificate（CertType=cas 必填 CertId + CertRegion 限 cn-hangzhou/ap-southeast-1）；WAF 3.0 走 wafopenapi 2021-10-01 CommonRequest 直调（SDK waf_openapi 包无域名/证书 API，与既有 waf.go 约定一致），绑定采用读改写：DescribeDomainDetail 快照 → 替换 Listen.CertId（map 形态保留未知字段）→ ModifyDomain 全量回写并透传 Redirect 防配置丢失
- ALB/NLB 绑定语义为替换监听默认证书保留扩展证书：读当前证书清单后 UpdateListenerAttribute 回写；监听 ID 全局唯一，通过逐账号地域 ListListeners(ListenerIds) 过滤定位地域，保持外部契约无 region 字段（对齐 tech-design DeployTarget）
- SDK mock 通过窄接口（casCertAPI/cdnCertAPI/dcdnCertAPI/albCertAPI/nlbCertAPI/wafCertCaller）+ CertAdapter 工厂字段注入实现，真实 SDK 客户端天然满足接口，不引入 mock 框架
- 限流不在此层自动重试（退避重试属变更执行编排层，见 tech-design Error Handling），仅映射 ErrCloudRateLimited 哨兵；CleanupOrphan 对已删除证书幂等成功，GetCert 对不存在证书返回 Exists=false 而非错误
- WAF 3.0 域名/证书 OpenAPI 按公开文档实现 + mock 测试，PoC 任务 5.12 联动验证后如有出入再校正（任务 Implementation Notes 约定）
