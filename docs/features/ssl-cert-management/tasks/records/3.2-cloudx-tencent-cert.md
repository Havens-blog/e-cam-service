### Key Decisions
- ErrCloudRateLimited 哨兵定义于 cloudx 公共层新文件 cert_errors.go（按 AC-3 指定位置），tencent 包再导出；3.1 阿里云侧哨兵为包内定义（SPEC CONTRADICTION：AC 称其位于公共层与实际不符），按 Hard Rule additive-only 不改 3.1 交付文件，阿里云对齐留待 5.3 统一抽象时收敛
- SSL 证书服务（ssl 2019-12-05）走 common SDK CommonRequest 直调（sslRPCInvoker），因 go.mod 未纳入 ssl 产品模块且任务注明 SDK 沿用仓库现有依赖；CDN/EdgeOne/CLB 用既有 cdn/teo/clb typed 模块的窄接口注入
- EdgeOne(waf)/CLB 引用 ResourceID 采用复合形态 {ZoneId}/{Host} 与 {LoadBalancerId}/{ListenerId}，自包含定位免绑定二次发现；CLB 绑定逐地域寻址（lbId 仅地域内唯一），SNI 多证书监听经 MultiCertInfo 整单回写（新证书主位、扩展与双向 CA 保留）
- UploadCert 显式 Repeatable=true：每次更换生成独立云证书副本，孤儿清理按 CloudCertMapping 归属收敛，避免复用仍被引用的存量证书；CleanupOrphan 传 IsCheckResource=true 云侧二次校验引用
- GetCert 优先解析 DescribeCertificateDetail 返回的 CertificatePublicKey PEM 计算 SHA256 指纹（对齐台账 ^[0-9a-f]{64}$）；无 PEM 回退 CertFingerprint（SHA1 形态，与台账口径不一致，已在注释登记 PoC 5.12 验证）
