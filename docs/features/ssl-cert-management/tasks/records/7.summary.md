## 4. Conventions Established
- 调度注册以行为等价优先于 1:1 任务注册：折叠/合一映射必须记录于包注释（probe 折叠进 inspection 防同日双重拨测先例）
- 每调度入口 guarded 包装标配：单飞互斥（防 ecron goroutine 重叠）+ panic recover（不击穿调度进程）
- cron 承载的运行参数一律装配期读取（DB 单文档阈值→Module 字段），运行期改动需重启并以注释声明；非整除行为与界值同注
- 队列复用 cam TaskModule 既有 taskx 实例（RegisterBillingExecutor 先例）不新建队列；依赖不可用时显式降级不阻断 boot
- 端口 nil 降级装配边界（5.summary 口径）→ 后续以端口桥（bridge）统一补生产实现，module.go 接线单点替换
- 审计仅追加 Hard Rule：DAO 只 Append+查询无 update/delete；报告存档并入审计单集合多投影，避免新增 cert 集合四处同步
- 去重唯一索引一律 partialFilterExpression（sparse 复合索引 null 键误伤，需真实实例验证口径）
- 权限面 deny-by-default：无角色/无有效码即 deny；角色集合语义，多能力码=多角色映射
- 审计写入分层：人工事件 handler 层、系统事件 service 层经端口（actor 归因不改冻结签名）；双写禁止（rollback 先例）
- 工程口径：wire CLI 全局安装 wire@v0.7.0 生成（go run 形态不可用，不扰动共享 go.sum）；go test ./... 以 -p 2 分批防 OOM；-race 免（宿主无 cgo）；新建文件 U+FFFD 扫描、CRLF 噪声以 tr -d '\r' delta=0 比对排除
