# Task Record: 5.8 回滚服务（GetCert 目标有效性三判定、仅成功项、rollback_failed 项级状态、ROLLBACK_TARGET_INVALID 转人工）

## Summary
实现变更回滚服务（ChangeRollbackService.Rollback）：仅 status=success 项参与回滚（失败/skipped 项引用未被改动仅在报告标记）；逐项前置 GetCert(oldCloudCertId) 三判定（Exists=false/NotAfter<now/Fingerprint≠订单 oldCertFingerprint）任一命中即整体阻断返回 ErrRollbackTargetInvalid（409 转人工）并记录审计，无任何状态变更；回滚经通道 Rollback 恢复旧证书 ID（K8s 项经 patch 恢复旧值，无云证书库三判定语境），成功项标 rolled_back，失败项标 rollback_failed + 立即发布 AlertCategoryRollbackFailed 告警（Hard Rule：不得静默，告警发布失败以聚合 error 上抛）；订单收敛：任一 rollback_failed → rollback_failed 终态、全部成功项回滚完成 → rolled_back、部分回滚保持 partial_completed 可续作；executing/verifying 入口先沿状态机白名单路径（executing→verifying→partial_completed）收敛并固化 protectUntil 后进入回滚终链；回滚产生的新云证书映射标 orphan 入 5.9 清理队列，OrphanCleaned 载荷记录入审计。配套新增 ItemStatusRollbackFailed 项级状态（domain/repository 校验器/schema.sql 同步）、ChangeItemRepository.FinishRollback CAS 原语（真实 Mongo 集成测试随仓内 DSN 门控）、CloudAPIChannel.InspectCloudCert 只读目标校验端口、RollbackTargetSource/RollbackAuditRecorder 注入端口（7.2 统一接线 internal/audit，nil=no-op）。
