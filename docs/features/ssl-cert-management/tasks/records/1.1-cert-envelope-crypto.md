### Key Decisions
- EnvelopeCrypto 以实例承载版本化密钥表（构造期展开为 cipher.AEAD，之后只读、可并发），Encrypt/Decrypt 签名与 AC 逐字一致；ioc 装配时调用 NewEnvelopeCryptoFromEnv 实现启动期 fail-fast（无任何版本或任一变量非法即报错）
- env 加载器 loadMasterKeys 独立为可注入 environ 的纯函数便于确定性测试；env 值约定 base64(StdEncoding) 且解码后必须恰好 32 字节，错误信息仅含变量名/版本号/长度，永不携带密钥材料
- Decrypt 使用 base64 Strict 解码并校验最小长度（nonce+tag），认证失败包装 ErrCiphertextAuthFailed（errors.Is 可判），失败路径一律返回 nil 明文
- Zeroize 原地清零底层数组后置 nil 释放引用，对 nil 指针/空切片安全；明文永不序列化为 string，无任何日志/错误/审计出口
