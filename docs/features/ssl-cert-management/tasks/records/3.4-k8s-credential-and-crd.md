### Key Decisions
- ErrK8sUnreachable 定义于 domain/errors.go（CertError 形态，Code=K8S_UNREACHABLE，对齐 tech-design 错误表 503 语义）；k8s 包构建失败与请求期 net.Error 族连接失败均以 %w 包装该哨兵，底层错误不透出（clientcmd/YAML 错误可能携带 kubeconfig 内容片段，Hard Rule 禁入日志/响应）
- 内置四类固定枚举以 k8s.BuiltinRegistrations 常量表承载（APIGroup/Version/Kind/Resource/CertFieldPath + GVR() 方法），5.6 K8sAPIChannel 直接复用（其任务文件明确'固定枚举 GVR 表与 3.4 共享常量'）；ALBConfig 组名按 Reference Files（tech-design/schema.sql 一致示例）取 alb.alibabacloud.com，certFieldPath 值为首期默认待 5.12 PoC 锁定（Ingress=spec.tls[].secretName、Gateway=spec.listeners[].tls.certificateRef.name、HTTPRoute=spec.parentRefs[].name 定位挂载 Gateway）
- 内置登记落地形态：EnsureBuiltinRegistrations(clusterID) 以 Create+唯一冲突跳过实现幂等播种（enabled=true、operator=system），不覆盖既有项 enabled 状态（保留人工停用）；AddCluster 经可选 BuiltinSeeder 依赖联动播种（nil 安全；播种失败显式报错但凭证已落库，幂等可重试）；内置项 Delete 返回 ErrBuiltinCrdRegistration 明确错误，SetEnabled 允许（停用=回归盲区显式声明）
- domain.CrdRegistrationRepository 增补 GetByID（删除/启停前定位登记项与内置判定依据；CertificateRepository.GetByID 同款契约，接口最小扩展）；certtest 增 FakeK8sCredentialRepo/FakeCrdRegistrationRepo 内存假实现（同既有 certtest 模式）
- certFieldPath 语法（ValidateCertFieldPath）：'.' 分段 + 段=标识符可选单个 '[]' 数组下钻后缀，拒绝空段/数字下标[0]/'[]'单独成段/多次[]/空白，错误信息含被拒路径与位置（AC 可读错误）；仅语法校验（登记判定'网关类资源含证书引用字段'由人工登记语义承载，5.6 扫描期消费路径解析）
- Factory 缓存：RLock 快路径 + 写锁 double-check 保证同集群同一 Client 实例；Invalidate 供凭证删除/更换后失效；DeleteCluster 经 ClientCacheInvalidator 可选依赖联动失效
