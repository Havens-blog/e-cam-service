### 2. Key Decisions
- [1.1] EnvelopeCrypto 以实例承载版本化密钥表（构造期展开为 cipher.AEAD，之后只读、并发安全）；ioc 装配调用 NewEnvelopeCryptoFromEnv 实现启动期 fail-fast（无版本或任一变量非法即报错）
- [1.1] 主密钥 env 值约定 base64(StdEncoding) 且解码后恰 32 字节；错误信息仅含变量名/版本号/长度，永不携带密钥材料
- [1.1] Decrypt 用 base64 Strict 解码并校验最小长度（nonce+tag）；认证失败包装 ErrCiphertextAuthFailed（errors.Is 可判），失败路径一律返回 nil 明文
- [1.2] repository 接口定义于 domain 子包、实现为未导出结构体 + 构造函数返回接口，直持 domain 模型（沿用 alert 域写法，免 12 组 domain↔dao 映射样板）
- [1.2] _id 采用 Mongo ObjectID（crd Create 预生成回填，driver 仅在 BSON 层补 _id 不回写结构体）；AlertConfig 固定 _id=`global`，Get 未命中返回 schema DEFAULT 填充配置
- [1.2] EnsureIndexes 幂等：集合不存在带校验器创建、已存在经 collMod 同步校验器后 CreateMany 补缺失索引；module init 调用点随 cert 模块装配任务落地
- [1.2] Upsert 类写路径（CloudCertMapping/Exemption/AlertConfig）不预填 _id，避免 $set 触碰不可变 _id 字段
- [1.2] 集成测试经 CERT_TEST_MONGODB_DSN 门控（缺省 127.0.0.1:27017），独立随机库结束 Drop，无 DB 优雅跳过保持 go test 绿
- [1.3] 验证环境选型：docker 与测试网络（118.145.73.93）不可达 → 官方 zip 拉起一次性本机 mongod 7.0.14（等价 compose mongo:7.0），生产库（106.52.187.69）零接触，验证后实例与工具已销毁

### 4. Conventions Established
- 模型字段/bson tag 与 schema.sql camelCase 1:1；新增字段必须三处同步：schema.sql + domain 模型 + validators.go，并依赖 EnsureIndexes 幂等同步到库
- repository 接口定义于 domain 子包；实现为未导出结构体 + New*Repository 构造函数返回接口；pkg/mongox.Mongo 注入
- 错误一律哨兵错误 + errors.Is 判定（不字符串匹配）；错误信息永不携带密钥材料/明文/凭证片段
- 明文密钥用后必须 defer domain.Zeroize；明文永不 string 化、不进日志/错误 message/响应体
- 主密钥 env 命名 `EIAM_CERT_MASTER_KEY_V<n>`（base64(StdEncoding) 32B）；写路径固定最大版本，轮换靠双读迁移
- repository 集成测试一律 CERT_TEST_MONGODB_DSN 门控 + 独立随机库 + 结束 Drop + 无 DB 优雅跳过
- 生产库零接触：schema 变更仅经 schema.sql 于开发库验证 + EnsureIndexes 幂等路径，不直连生产执行 DDL
