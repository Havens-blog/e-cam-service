### 2. Key Decisions
- [2.1] 链完整性判定 = 上传束内 leaf 可验证至自签名锚（自签名 leaf 视为完整）；仅 leaf 或缺中间证书 → CERT_CHAIN_INCOMPLETE
- [2.1] 有效性先于链构建显式校验，链验证以 leaf 有效期中点为时钟——过期（CERT_PARSE_FAIL）与链不完整（CERT_CHAIN_INCOMPLETE）互不掩盖
- [2.1] SAN 结构规则：leaf 无 DNS SAN 且无 CN → CERT_PARSE_FAIL；SAN 扩展畸形在 x509 解析期失败；IP SAN 解析但不计入域名 SAN 清单
- [2.1] 私钥零化边界：ParseCertAndKey 仅零化自有 DER 拷贝（domain.Zeroize），调用方 keyPEM 缓冲区永不突变（2.2 校验后仍需加密）——契约文档化并由 TestParseCertAndKeyDoesNotMutateInputs 钉死
- [2.1] keyAlgorithm 枚举限 RSA|ECDSA（对齐 schema enum）；其他算法（如 Ed25519）→ CERT_PARSE_FAIL
- [2.2] SPEC GAP 补齐：schema.sql 原未持久化证书材料、补传私钥无法重跑匹配校验 → 新增 cert_certificates.certPem（导入束原文，仅校验/云上传依据，永不出现在 API 响应）；schema.sql 与 models_test 预期清单同步保持 1:1
- [2.2] expectedDomain 不一致仅提示不拦截，提示放响应 meta.expectedDomainMissing（Hard Rule：data 仅 certId/fingerprint/hostingStatus 三字段）
- [2.2] 批量导入会话先持久化再 goroutine 派发（浏览器中断后轮询仍可见）；逐文件 recover 兜底 panic 落 INTERNAL_ERROR errorReason；批处理整体 10min 超时防泄漏
- [2.2] 批量证书/私钥按去扩展名基名配对（a.crt↔a.key，小写），同名冲突取首个
- [2.2] AttachPrivateKey 密文写入与 hostingStatus=complete 同一原子 update；web 层错误码映射用固定安全文案（不回显 err.Error()），500 详情仅进日志
- [2.3] daysLeft 筛选令牌 gt30/le30/le14/le7/expired 在 service 层翻译为 notAfter 区间（expired=notAfter<=now；leN=now<notAfter<=now+N*24h；gt30=notAfter>now+30d），仓储保持纯区间查询
- [2.3] referenceStatus「涉及云/产品」取该指纹跨快照累计引用历史；空涉及集被任一成功快照空泛覆盖（no_refs_scanned）；blind_spot=无 done 快照或最新 done 快照 coverageMeta 存在未覆盖云/产品对
- [2.3] 列表 refCount 与 stats 分母均只取最新 status=done 快照；running/failed 快照永不参与（含 failed 排除测试）
- [2.3] 删除拦截返回类型化 *domain.DeleteBlockedError → 409 CERT_HAS_REFS，结构化 meta {referenceStatus, refCount, reason, protectUntil}（盲区原因与保护期截止机器可读）
- [2.3] stats 每次请求实时从仓储聚合（Hard Rule：无存储快照）；比率 4 位小数，y=0 分母守卫
- [2.3] 搜索 regexp.QuoteMeta + 大小写不敏感 $regex 跨 commonName/sans/fingerprint（沿用 internal/cam/tag 惯例）

### 4. Conventions Established
- API 统一 {success,data,error,meta} 信封；错误码→HTTP 映射只在 web 层做一次，文案固定安全（不回显 err.Error()），500 详情仅进日志
- 响应 data 字段最小化白名单（导入成功仅 certId/fingerprint/hostingStatus）；提示性信息一律放 meta（如 expectedDomainMissing）；私钥明文/密文永不出现于响应/日志/错误 message，契约测试逐响应断言
- 测试夹具统一经 internal/cert/certtest（现场生成 PKI + 内存假仓储）确定性运行，无 MongoDB 依赖；仓储集成测试沿用 Phase 1 CERT_TEST_MONGODB_DSN 门控 + 独立随机库 + 无 DB 优雅跳过
- 持久化新增字段三处同步：schema.sql + domain 模型 + validators.go（Phase 1 约定，2.2 certPem 已实践）
- 仓储方法保持纯查询语义（daysLeft 分层在 service 层翻译为 notAfter 区间）；状态+数据一致性变更用同一原子 update（AttachPrivateKey 范式）
- 异步批处理模式：会话先持久化再派发 goroutine、逐文件隔离 recover 落 errorReason、整体超时兜底、轮询终态收敛（completed/partial_failed）
- 搜索输入 regexp.QuoteMeta + 大小写不敏感 $regex（对齐 internal/cam/tag）
- 统计/派生口径：仅最新 status=done 快照参与；查询期实时聚合不落存储快照
