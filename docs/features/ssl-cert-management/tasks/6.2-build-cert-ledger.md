# 6.2: 台账组件构建（UF-1：统计卡/表格/导入 Modal/批量导入/删除拦截/补传私钥，含 loading/empty/error 态）

## Description
构建 /certs 台账页全部组件：统计卡行（完整托管/仅指纹/覆盖率两口径）、证书表格（搜索/筛选/分页/保护期标记）、导入 Modal（单张，含阶段化 loading 与四类校验错误展示）、批量导入 Modal（多文件+逐文件结果+单文件重试）、删除拦截/二次确认、补传私钥 Modal。Vercel 设计规范 + Element Plus 组件。

> 跨仓库任务：文件位于 e-cam-web 仓库，路径为仓库相对路径。

## Acceptance Criteria
- [ ] 统计卡行（3 列）：完整托管数 / 仅指纹登记数（含占比）/ 覆盖率（登记率+可更换托管率），数据绑定 GET /api/v1/certs/stats。
- [ ] 表格：列（域名/SAN·签发者·有效期·剩余[状态色]·托管状态·保护期[锁徽章]·引用数·操作）；搜索+托管状态/剩余天数筛选+服务端分页（20/页）；行点击进详情；SAN chips 超 3 个折叠+N；指纹类 mono 截断（首8…末8）+复制。
- [ ] 导入 Modal：PEM+私钥(可选)+预期域名(可选)；提交合并 loading（按钮 disabled+spinner+阶段文案，不可关闭）；校验失败表单顶部 Error 横幅逐项列错误（四类 CERT_*）；expectedDomain 不一致仅 Warning 提示不拦截；成功关闭+Toast+列表刷新置顶。
- [ ] 批量导入 Modal（720px）：多文件/拖拽+逐文件可选私钥+zip 解包；处理中进度条+计数+不得中途关闭（关闭需二次确认）；逐文件结果列表（成功[完整/仅指纹]/失败+原因）+失败行单文件重试；完成 Toast N成功/M失败；中断重入展示上次会话结果（batchId 轮询恢复）。
- [ ] 删除与补传私钥：有活跃引用/保护期 → 拦截 Modal 仅说明原因（N 个引用/保护期至 X 日）无删除按钮；可删 → 红色后果二次确认后删除+Toast；仅指纹行"补传私钥"→ 匹配校验通过即时升级完整托管，失败展示 CERT_KEY_MISMATCH。
- [ ] 四态齐备：loading 骨架（5 行+3 卡）/empty（空态引导批量导入）/error（重试）/populated；a11y：label 关联、focus ring、错误 aria-describedby。

## Hard Rules
- 任何界面不展示明文私钥；详情/列表私钥仅显示"已加密托管"状态。
- 导入提交终态到达前 Modal 不可关闭、按钮 disabled（防重复提交）。

## User Stories
Story 1（导入新购证书 — 全部 AC）、Story 4（存量批量导入与补传私钥升级）。
