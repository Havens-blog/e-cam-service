# 5.10: 验证窗口服务（verifyExpected+excludedDomains、提频探测 verifyConfirmProbes、window-expiry 终局判定、UnmetDomains）

## Description
变更后验证窗口：批执行完成时固化 verifyExpected{newCertFingerprint,domains[],excludedDomains[],windowUntil}（豁免域名剔除入 excludedDomains，计 skipped 不阻塞达标）；窗口内对该批域名提频探测（verifyProbeIntervalMinutes），连续 verifyConfirmProbes 一致达标；window-expiry 终局判定（全部达标→completed；未达标→partial_completed + UnmetDomains 写入 ChangeReport + 恢复常规告警）；change_linked_diff 路由。

## Acceptance Criteria
- [ ] 固化 verifyExpected：批执行完成时按该批目标域名构建 domains[]，剔除当前豁免清单命中域名写入 excludedDomains[]（豁免项验证计 skipped 不参与达标判定），设 windowUntil=now+verifyWindowHours；分批单每批按该批域名刷新。
- [ ] 提频探测：订单 verifying 期间对 verifyExpected.domains 探测周期由天级提至 verifyProbeIntervalMinutes；连续 verifyConfirmProbes 次一致=批级达标 → 批间暂停（paused=true/pausedAt）等续批或窗口提前达标关闭。
- [ ] window-expiry 终局判定函数 `FinalizeExpiredWindows(ctx)`：扫 verifyWindowUntil <= now 且 status=verifying 单据——全部达标→completed；存在未达标→partial_completed + 未达标域名写入 ChangeReport.UnmetDomains（Verify.Unmet 计数）+ 恢复常规 diff 告警。
- [ ] change_linked_diff 路由：窗口内 diff 且 domain∈verifyExpected.domains 且线上指纹=newCertFingerprint → 走变更关联通道（4.3 verifyWindowRoute）；窗口关闭后恢复常规 diff 判定。
- [ ] 豁免∩窗口不死锁：豁免域名进 excludedDomains 计 skipped，窗口仍可正常达标（含通配符无 override 也计 skipped）。
- [ ] 集成测试：豁免∩窗口达标、提前达标关闭、window-expiry 转 partial_completed+UnmetDomains、change_linked_diff 路由、分批 verifyExpected 刷新。

## Hard Rules
- 窗口达标判定不依赖被动探测触发——window-expiry 必须由 scheduler 主动扫描终局判定。
- 豁免域名/无 override 通配符验证项必须计 skipped，不得阻塞窗口达标（防"含豁免域名的窗口永不达标"死锁）。
