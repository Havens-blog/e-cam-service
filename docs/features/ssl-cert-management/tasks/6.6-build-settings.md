# 6.6: 全局配置组件（UF-5：告警/豁免/CRD 登记/阈值界值）

## Description
构建 /certs/settings 全局配置页（仅运维主管/审计可见）：卡1 告警接收（webhook mono 输入+邮件 tag 输入+发送测试+保存）、卡2 探测豁免清单（增删+审计提示）、卡3 阈值参数（界值范围内滑块/数字输入，越界禁存）、CRD 登记管理（增删查+重复 409 处理）、渠道未确认横幅。

> 跨仓库任务：文件位于 e-cam-web 仓库，路径为仓库相对路径。

## Acceptance Criteria
- [ ] 卡1 告警接收：webhook URL（mono）+ 邮件接收组（tag 输入）+ 发送测试（结果 Toast 成功/失败原因）+ 保存（URL/邮箱格式校验失败行内提示）。
- [ ] 卡2 豁免清单：表格（子域名/原因/操作人/时间/移除）+ 添加豁免 Modal（子域名+原因）；增删后列表即时更新；变更留审计提示。
- [ ] 卡3 阈值参数：scanFreshnessHours(1~72)/verifyWindowHours(2~24)/rollbackProtectDays(7~14) 等全部 thresholds 以数字输入/滑块呈现，界值与后端一致；越界 Error 边框+合法区间提示+保存禁用。
- [ ] CRD 登记管理：登记表单（clusterId+apiGroup+kind+certFieldPath）+ 列表（含 enabled）+ 删除（回归盲区提示）；重复登记 409 行内错误。
- [ ] 渠道未确认（channelConfirmed=false）顶部 Warning 横幅"告警渠道未确认，相关验收标准不在范围"；就绪后消失。
- [ ] 状态：loading 三卡骨架/读取失败重试（表单不可编辑）/保存异常行内错误且保留输入不清空/empty"尚未配置接收人"。

## Hard Rules
- 阈值界值前端校验仅为体验，保存前服务端仍校验（PUT 越界 400 需正确呈现行内错误）。
- 页面整体对非主管/审计角色前端隐藏+路由拦截（6.1 已注册拦截，组件内不重复实现）。
