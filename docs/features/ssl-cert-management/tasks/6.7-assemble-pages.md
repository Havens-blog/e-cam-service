# 6.7: 页面装配（6 页面路由/组合/导航注册，Page Composition 表全页落地）

## Description
将 6.2-6.6 构建的组件装配为最终页面并打通跨页流转：Page Composition 表 7 路由全页落地（/certs、/certs/:id、/certs/dashboard、/certs/changes、/certs/changes/new、/certs/changes/:id、/certs/settings）、导航注册核对、只读角色端到端核验、跨页流（台账→详情、发起更换→向导预选、列表行→报告、报告→配置）。

> 跨仓库任务：文件位于 e-cam-web 仓库，路径为仓库相对路径。

## Reference Files
- docs/features/ssl-cert-management/design/tech-design.md — Integration Specs（e-cam-web 新模块）、Architecture / Layer Placement
- docs/features/ssl-cert-management/ui/ui-design.md: Page Composition 表 + 只读角色路由拦截
- docs/features/ssl-cert-management/prd/prd-ui-functions.md: Page Composition / Navigation Architecture / Navigation Rules
- docs/features/ssl-cert-management/ui/prototype/index.html: 导航总览原型

## Acceptance Criteria
- [ ] Page Composition 表 7 路由全部渲染真实组件（替换 6.1 占位页）：每页与 ui-design Component 定义一致（布局/状态/交互抽验）。
- [ ] 跨页流转打通：台账行→详情（面包屑回台账）；台账"发起更换"→向导 ?certId= 预选；变更列表行→报告详情（面包屑回列表）；报告页"配置"→设置页（仅主管可见入口）；看板抽屉"查看证书详情"→/certs/:id。
- [ ] 只读角色端到端核验：仅"到期看板"菜单；/certs、/certs/changes、/certs/changes/new、/certs/changes/:id、/certs/settings 拦截提示；/certs/dashboard 与 /certs/:id 可达（详情只读模式无操作入口）。
- [ ] 导航注册核对：证书台账/到期看板/变更管理 三一级菜单图标（certificate/clock-alert/swap）与顺序按 prd-ui-functions；面包屑/返回导航按 Secondary Pages 表。
- [ ] 全模块构建与既有页面回归：`npm run build` 通过；既有模块路由/菜单无回归（手工抽验 2-3 个既有页面可达）。
- [ ] 空态链路：无证书时台账 empty→批量导入引导；无变更单时列表 empty→新建变更引导。

## Hard Rules
- 不新增 Page Composition 表之外的页面/路由。
- 装配不改动 6.2-6.6 组件内部逻辑（仅组合与路由级接线；发现组件缺陷回对应 Build 任务修复）。

## User Stories
全部 Story 的页面承载（Story 1-6 前端入口收口）。

## Implementation Notes
- 跨仓库（e-cam-web）：主要工作在 `src/views/cert/*/index.vue` 页面级组合与 `src/router/routes.ts` 核对（占位替换、meta/hideInMenu 校正）；必要时微调 `src/api/cert.ts` 缺失方法。
- 验收方式：本地起 e-cam-service（mock 或开发库）+ e-cam-web dev 联调走通主流程（导入→扫描→清单→执行[模拟通道]→报告）；构建产物通过。
- 只读角色核验可用测试账号或角色 mock（eiam-mapper 机制）。
