# 5.4: 阿里云部署器（CDN/DCDN/WAF/LB 两段式绑定+孤儿候选+限流退避上限）

## Description
阿里云 CloudDeployer 实现：将 3.1 cloudx 阿里云证书 API 组装为 internal/cert/deployer 层的部署器，覆盖 CDN/DCDN/WAF/ALB(NLB) 产品；经 5.3 CloudAPIChannel 编排调用；限流退避有上限（耗尽 → failed，不无限重试）；产出 DeployResult（NewCloudCertID/OldCloudCertID/OrphanCandidate）。

## Reference Files
- docs/features/ssl-cert-management/design/tech-design.md — Interfaces / Interface 1: ExecutionChannel、Interface 2: CloudDeployer
- docs/features/ssl-cert-management/design/tech-design.md: Error Handling 限流→rate_limited 退避 (ref: Interface 1: ExecutionChannel)
- docs/features/ssl-cert-management/design/schema.sql: cert_change_items resourceRef cloud_api 分支字段 (ref: Interface 2: CloudDeployer)

## Acceptance Criteria
- [ ] AliyunDeployer 实现 CloudDeployer（供 5.3 CloudAPIChannel 注入）覆盖 cdn/dcdn/waf/alb/nlb 五产品；按 DeployTarget.product 路由到对应 3.1 适配方法。
- [ ] Deploy 返回 DeployResult{NewCloudCertID, OldCloudCertID, OrphanCandidate}；OldCloudCertID 从引用快照读取（执行前），供回滚依据。
- [ ] 限流：`ErrCloudRateLimited` → 退避重试（固定序列，有界上限），耗尽 → 项标 failed（rate_limited 状态由 5.7 引擎承接），绝不无限重试阻塞任务。
- [ ] 第二段绑定失败 → CleanupOrphan 清理未绑定云侧证书 + OrphanCandidate=true（映射表 active→orphan，供 5.9 消费）。
- [ ] mock SDK 测试：两段式成功、第二段失败→补偿清理、限流退避至耗尽、五产品路由。
- [ ] `go build ./internal/cert/...` 全绿；不修改 3.1 适配签名。

## Hard Rules
- 退避重试必须有上限次数与总时长，禁止无限重试。
- 不在 deployer 层做业务级状态机判断（成功/失败/回滚语义归 5.7/5.8）。

## User Stories
Story 3（一键批量更换 — 阿里云批量执行 + 孤儿证书补偿清理）。
