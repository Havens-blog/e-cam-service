# 5.6: K8sAPIChannel（三信号管理权探测、patch 仅证书字段、recheckDelayMinutes 复检、AutoChangeable 标记）

## Description
ExecutionChannel 的 K8s 实现：Discover 按固定枚举(ALBConfig/Ingress/Gateway/HTTPRoute)+enabled CrdRegistration 遍历、按 certFieldPath 读证书引用字段产 CertReference（含 namespace/kind）；Deploy 前/生成期三信号管理权探测（GitOps label/ownerReferences/cert-manager annotation）→ AutoChangeable=false + Reason；Deploy 仅 patch 证书引用字段、保留 oldCloudCertId；recheckDelayMinutes 后单轮复检（reconcile 回写 → failed + 告警）。

## Acceptance Criteria
- [ ] Discover：固定枚举四类 + enabled=true CrdRegistration（clusterId+apiGroup+kind+certFieldPath）遍历；按 certFieldPath 读证书引用字段产 CertReference{cloud=…,product=crd,clusterId,namespace,kind,resourceId,referencedCloudCertId}；未登记/enabled=false CRD → 盲区声明。
- [ ] 三信号管理权探测（任一命中 AutoChangeable=false，Reason 记信号类型+具体键）：GitOps label（默认 argocd.argoproj.io/*、fluxcd.io/* 可 config）、ownerReferences 非空、管理 annotation（cert-manager.io/issuer|cluster-issuer）。
- [ ] Deploy：仅 patch 证书引用字段（JSON Patch 指向 certFieldPath，不动其他字段）；执行前读 oldCloudCertId 保留；K8S_UNREACHABLE → failed + error=K8S_UNREACHABLE；patch 产出 DeployResult{RecheckPassed=待复检}。
- [ ] Recheck 函数 `RecheckCRDField(ctx, item)`：patch 后延迟 recheckDelayMinutes 单轮复检——仍为新证书 ID → RecheckPassed=true/success；被 reconcile 回写旧值/其他值 → RecheckPassed=false/failed + 告警（TLS 差异通道语义，附 orderId/itemId）；复检次数固定 1，失败转人工。
- [ ] AutoChangeable 标记回填：5.2 清单生成时对 K8s 项调本通道管理权探测接口决定 AutoChangeable。
- [ ] 测试：fake dynamic client（或 envtest 假 APIServer）覆盖三信号各命中、patch 仅证书字段、复检通过/回写失败、盲区声明。

## Hard Rules
- patch 必须仅作用于证书引用字段，不得整对象覆盖（防 reconcile 风暴与误改其他字段）。
- 复检次数固定 1，失败不做二次自动复检（转人工）。
