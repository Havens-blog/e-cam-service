# 3.6: 引用查询 API（正向分组+覆盖率、反向查询、立即扫描防重 409 SCAN_IN_PROGRESS）

## Description
引用关系读取端点：正向（按证书分组展示引用资源 + 扫描元数据/覆盖率 + 盲区声明 + referenceStatus）、反向（域名/资源 → 证书，按指纹区分并存证书）、立即扫描触发（防重）。

## Reference Files
- docs/features/ssl-cert-management/design/tech-design.md — 引用状态语义（"未发现引用" ≠ "无引用"）、Error Handling / Error Types & Codes
- docs/features/ssl-cert-management/design/api-handbook.md: 引用关系三端点契约 (ref: 引用状态语义（"未发现引用" ≠ "无引用"）)
- docs/features/ssl-cert-management/prd/prd-user-stories.md: Story 2 AC（分组/覆盖率/盲区声明/指纹区分）

## Acceptance Criteria
- [ ] `GET /api/v1/certs/:id/references`：按云/产品/集群分组的引用列表（resourceId/referencedCloudCertId/accountKey/namespace/kind）+ 扫描元数据（lastScanAt + coverage 各云各产品，total=-1 输出"分母不可用"标记）+ referenceStatus（has_refs/no_refs_scanned/blind_spot）+ 盲区声明字段（覆盖边界）。
- [ ] 未发现引用语义：referenceStatus=no_refs_scanned 时响应明确区分于无扫描（blind_spot），附最近扫描时间。
- [ ] `GET /api/v1/certs/reverse?domain=`：按域名/资源名反查所引用证书列表，多证书并存按指纹分组互不混淆；无匹配 → 空列表（区别于错误）。
- [ ] `POST /api/v1/certs/:id/scan`：触发 3.5 扫描任务；进行中 → 409 SCAN_IN_PROGRESS（附进行中快照信息）。
- [ ] httptest 契约测试：三分支 referenceStatus、reverse 指纹区分、防重 409、错误信封格式。

## Hard Rules
- 正向响应必须携带覆盖边界声明（"本视图不含 VM Nginx 配置级引用"），不可省略。
- 反向查询按指纹严格区分，不做同域名合并。
