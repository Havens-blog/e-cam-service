## Phase 1 — 推理审计（跨文档一致性）

### 发现 1（中高）：回滚路径与回滚保护期的归属，图 ↔ 正文矛盾

- Mermaid 回滚成功路径：`S -->|是| X[恢复正常告警规则<br/>变更报告:已完成/部分完成<br/>进入回滚保护期 7~14天]`——图示**回滚后的变更单进入回滚保护期**，且报告标注"已完成/部分完成"。
- 但 spec 状态机（L100）：`已完成 / 部分完成 → 已回滚 / 回滚失败(转人工) → 关闭`，且明文"**回滚保护期为已完成/部分完成状态的附属属性**"——已回滚是独立终态，按正文不属于保护期附属状态。
- 佐证：UF-4 状态表（L207-219）与变更单列表状态枚举（L201"草稿/待确认/执行中/验证中/已完成/部分完成/已回滚/回滚失败"）中，**"已回滚"没有任何展示行定义**（无报告入口？无保护期剩余？无后续动作引导）。回滚是本功能的核心安全机制，回滚完成后的系统状态（旧证书删除保护、报告归属、用户下一步）在图、正文、UI 三处给出三种粒度的答案。
- 处理：按扣分规则记 **-30（跨节冲突）**，计入 Flow Diagrams 维度；"已回滚"UI 态缺失另行计入 Functional Specs。

### 发现 2（中）：Goal"回滚成功率 100%"与系统自身定义的"回滚失败"态冲突

- Goals 表（L41）："回滚成功率 100%（回滚对象 = 本次变更执行成功的资源，且限通过目标有效性校验的项）"。
- 同文档 In Scope（L54）与状态机（L100）均定义"**回滚自身失败立即告警并转人工**"、`回滚失败(转人工)` 终态；UF-4 亦有"回滚失败 | 告警横幅 + 转人工提示"状态行。
- 100% 成功率目标针对一个系统自身预设了失败路径的操作，一旦发生一次合法回滚失败即永久不可达成，该指标不可验收。属典型"不可客观验证的量化目标"。计入 Background & Goals（逻辑一致性）。

### 发现 3（轻中）：无私钥导入的校验集合未定义

- UF-1 步骤 2（L55）："上传 PEM + 私钥（**私钥可选项，缺省走仅指纹登记**）"；校验规则（L82）："导入校验：证书/私钥匹配、证书链完整、有效期、SAN 解析"。
- "证书/私钥匹配"对无钥导入如何处理、无钥导入是否仍执行链/有效期/SAN 拦截（已过期的存量证书导入是拦截还是登记？），三文档均无定义。Story 4 只说"不含私钥者登记为'仅指纹登记'"，未给无钥路径的失败条件。计入 Functional Specs（校验规则）与 Edge Case。

### 发现 4（轻）：其余核对项（未达冲突阈值，折入维度分）

- 状态机含"→ 关闭"，但全文无任何场景描述变更单如何/何时进入"关闭"，UF-4 状态枚举亦无"关闭"（折入 Scenario / Functional Specs）。
- 执行中发起回滚（入口声明"执行中（出现失败项后）……均可用"）与仍在执行/排队中的剩余项的并发关系（回滚是否中止未执行项）未定义（折入 Edge）。
- 回滚范围 AC"回滚将成功项引用恢复为旧证书 ID"——是全部成功项一键回滚还是可选子集（验证窗口内仅 1/N 项异常时是否全量回退）未定义（折入 User Stories 可验证性）。

## Phase 3 — 盲区猎杀（[blindspot]，均含引文，均处于评分维度之外）

1. **[blindspot] 回滚成功后云侧残留的新证书成为无主孤儿** — spec In Scope："第二段失败时依据映射表补偿清理未绑定的云侧孤儿证书"。孤儿清理只覆盖"绑定失败"一种成因；正常执行成功后用户回滚（"回滚作用于本次变更中执行成功的资源（将其引用恢复为旧证书 ID）"）时，两段式第一段已上传到各云证书库的新证书成为**未绑定残留**，且映射表已产生记录——是否清理、映射表是否失效、不清理时云侧证书库的膨胀与审计口径，三文档均无答案。

2. **[blindspot] 执行中阶段的天级 TLS 探测会触发常规差异告警误报** — spec："天级巡检：……TLS 探测（未豁免端点）"，而验证窗口的定义是"**变更后**进入验证窗口"。批量执行可持续分钟到小时级（"单轮扫描分钟到小时级"同量级），两段式第一段完成、第二段进行中时端点呈中间态，此刻天级探测命中"线上≠台账"即走**常规差异告警**（而非变更关联告警），在窗口开启前制造误报风暴。"扫描与执行并发"条只冻结了清单快照与视图展示，未抑制执行中阶段的探测告警。

3. **[blindspot] 回滚保护期承诺与被动校验之间的空窗** — spec："回滚前校验回滚目标有效性（云侧证书库中旧证书仍存在且未过期；已删除/已过期则不自动回滚）"。该校验仅在用户发起回滚瞬间执行；保护期（7~14 天）内旧证书被他人/其他系统在云侧删除时，平台无任何主动发现与告警——直到有人需要回滚才发现"想回滚也回不了"。保护期的存在意义（保证可回退）与实际保障机制（被动校验）不匹配。
